# Integration Directory

Discover Linear add-ons or build your own

![Linear icon next to integration icon](https://webassets.linear.app/images/ornj730p/production/b29db83e0238c6adea3c3a6d86834734fe332f29-2880x1620.png?w=1440&q=95&auto=format&dpr=2)

## Overview[⁠](https://linear.app/developers/integration-directory.html#overview)

Linear’s [Integration Directory](https://linear.app/integrations.html) features apps and add-ons created by the Linear team as well as external applications. Install these to improve your workflow and sync with your favorite tools. You can also build your own integrations and submit them to the directory.

## Basics[⁠](https://linear.app/developers/integration-directory.html#basics)

### Linear crafted[⁠](https://linear.app/developers/integration-directory.html#linear-crafted)

If you see an integration with a verified badge on the icon, that means it was crafted by the Linear team. You can install them via the link in the directory or by going to [*Settings > Workspace > Integrations*](https://linear.app/settings/integrations/github.html) and then select the integration name.

For most integrations, you’ll have to be a workspace admin to install them for your workspace. If you don’t know who is an admin, go to [*Settings > Workspace > Members*](https://linear.app/members.html) and filter for Admins.

### Third-party integrations[⁠](https://linear.app/developers/integration-directory.html#third-party-integrations)

The directory also features over 250 integrations built by other apps and third parties. We recommend doing your own research into the integration owner and permissions required before installing these integrations. You can find the creator’s website and contact in the sidebar.

### Build your own[⁠](https://linear.app/developers/integration-directory.html#build-your-own)

Use [Linear’s API](https://developers.linear.app/docs/) to build your own integration and submit it to the directory following the instructions below. We recommend building applications using [OAuth](https://developers.linear.app/docs/oauth/authentication) and having a separate workspace for the application, which gives all admins access to the application (instead of only the application creator).

We’ll accept integrations that we think are useful to the community and are built by formal companies. We generally do not accept scripts, low-effort/vibe coded or apps built by hobbyists, but feel free to reach out to [integrations@linear.app](mailto:integrations@linear.app) if you think it should be included. You can also ask questions and see what others are building in our Slack community’s [#api channel](https://linear.app/join-slack.html).

![Figma file screenshot of Linear integration template](https://webassets.linear.app/images/ornj730p/production/597944e28167f567525f4b602ad72c3db65a973d-1504x933.png?w=1440&q=95&auto=format&dpr=2)

### Submit your integration[⁠](https://linear.app/developers/integration-directory.html#submit-your-integration)

1. Fill out this [form](https://docs.google.com/forms/d/e/1FAIpQLSdYKtml_JsVv-sXuP4_eiT-l-8K6IaoEQrxdAP_7w-mb1-hSQ/viewform?usp=sf_link). It includes a sample page to give you a sense of copy style and length.
2. Submit assets to [integrations@linear.app](mailto:integrations@linear.app) or include a link in the form. We’ve built a [template in Figma](https://www.figma.com/community/file/1111754695287344546) to make this easy. If you’re not familiar with Figma, make sure to include the following images:

* Color icon 320px by 320px in .svg, .jpeg, or .png file format
* Monochrome (white) icon 320px x 320px in.svg, .jpeg, or .png file format
* Showcase images (1-3 max) 1600px x 1000px in .svg, .jpeg, or .png file format
  + Defer away from simple screenshots of your app, and design it to best represent your integrations functionality. [Example 1,](https://linear.app/integrations/cursor.html) [Example 2](https://linear.app/integrations/figma.html).

### Update or delist an integration[⁠](https://linear.app/developers/integration-directory.html#update-or-delist-an-integration)

If you require any changes to your listing such as copy, image updates or removing your listing if you no longer provide your service, you can contact [integrations@linear.app](mailto:integrations@linear.app) with the updates required.
