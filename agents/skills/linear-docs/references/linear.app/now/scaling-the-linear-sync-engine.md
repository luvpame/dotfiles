# Scaling the Linear Sync Engine

![A frame from the presentation where Tuomas explains how the sync engine works.](https://webassets.linear.app/images/ornj730p/production/24a36a5e1491f344804a16a9e6255a6fa2b332f1-6400x3600.png?q=95&auto=format&dpr=2)

[Tuomas Artman](https://linear.app/now/author/tuomas-artman.html)·June 29, 2023

How does Linear’s realtime sync engine work behind the scenes? In this talk, I cover the challenges we’ve had scaling the sync engine, how the API around it has formed because of those challenges, and how the sync engine works in the Linear application today.

A few years ago, I gave [a talk at React Helsinki](https://www.youtube.com/watch?v=WxK11RsLqp4&t=2175s) about how the Linear realtime sync engine works behind the scenes.

We have come a long way since then, so we recorded a sequel to that talk at our company offsite a few weeks ago. In this video we cover the challenges we’ve had scaling the sync engine, how the API around it has formed because of those challenges, and how the sync engine works in the Linear application today.

If you want to experience the sync engine in action, you can [sign up for a Linear account](https://linear.app/signup.html) (it’s free!) and test it yourself.

Interested in helping us scale the sync engine (and Linear) to the next level? [We are hiring for a variety of roles](https://linear.app/careers.html) across Europe and North America.
