# Third-Party App Approvals

Enable third-party application approvals for your workspace to maintain control over which applications can be installed.

Available to workspaces on any paid plan.

![Login screen on the Linear desktop app](https://webassets.linear.app/images/ornj730p/production/29a3c7c63cca5f8798560909ad3473e5e788f8e8-5760x3536.png?w=1440&q=95&auto=format&dpr=2)

## Overview[⁠](https://linear.app/docs/third-party-application-approvals.html#overview)

Requiring approval for third-party applications ensures that the people with permission to manage apps control which applications can access the workspace and its data.

## Configure[⁠](https://linear.app/docs/third-party-application-approvals.html#configure)

1. Third-party application approvals are available on any paid plan.
2. A workspace owner in an Enterprise workspace—or a workspace admin in any other paid workspace—can turn on third-party application approvals from [Settings > Administration > Security](https://linear.app/settings/security.html).
3. [Apps that have been approved or denied will show up in Applications](https://linear.app/settings/applications.html).

## Requesting approval[⁠](https://linear.app/docs/third-party-application-approvals.html#requesting-approval)

When a workspace member tries to install a third-party app, Linear will display a screen which allows the member to request approval and optionally include a reason for their request. If the application has already been denied previously, Linear will let the requestor know and share the reason.

## Notifications[⁠](https://linear.app/docs/third-party-application-approvals.html#notifications)

Workspace owners in Enterprise workspaces—and workspace admins in all other paid workspaces—will receive an email and an in-app notification when an application has been requested for approval. This notification will contain a link to the workspace applications page so you can approve or deny the application swiftly.

Once the application has been approved or denied, the member who requested the application will also receive an email and an in-app notification. When denying a request, they can include an optional reason. This reason will be shared with the member who made the request.
