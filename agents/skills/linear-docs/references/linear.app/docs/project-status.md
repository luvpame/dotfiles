# Project status

Project statuses clarify where each project is in its lifecycle

Workspace-level project statuses are available on all plans. Team-specific project statuses are available on [Business](https://linear.app/pricing.html) and [Enterprise](https://linear.app/pricing.html) plans.

![Project status](https://webassets.linear.app/images/ornj730p/production/d0cd238fd35bbe86e9d30f274cf9e5ccaafc3832-1168x1268.png?w=1440&q=95&auto=format&dpr=2)

## Overview[⁠](https://linear.app/docs/project-status.html#overview)

A project status offers a quick update for stakeholders to gauge the progress of the project. The status will appear next to the project name in the initiative or project timeline pages as well as in an icon on the project bar.

## Change a project’s status[⁠](https://linear.app/docs/project-status.html#change-a-project's-status)

To change a project’s status, open the project, select its status in the overview or project details sidebar, and choose a new status.

## Create a custom project status[⁠](https://linear.app/docs/project-status.html#create-a-custom-project-status)

Workspace admins can customize the names, descriptions, and colors of workspace-level project statuses in Settings > Projects > Statuses.

On Business and Enterprise plans, teams can manage their own project statuses in Team settings > Team project statuses, or inherit statuses from a parent team or the workspace.

Teams managing their own statuses can also set their order. Changes to a parent team’s statuses apply to sub-teams that inherit them. A project uses the statuses available to its lead team, even when other teams contribute to it.

## When a project’s available statuses change[⁠](https://linear.app/docs/project-status.html#when-a-project's-available-statuses-change)

When a team changes which project statuses it uses, affected projects may move to an available status. If a project’s lead team changes, Linear keeps its current status when it remains available. Otherwise, Linear looks for an available status with the same name and lifecycle category, then another status in that category.
