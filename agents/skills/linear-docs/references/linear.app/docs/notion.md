# Notion

Preview Linear issues and more directly from Notion

![Linear logo next to Notion logo](https://webassets.linear.app/images/ornj730p/production/aa059b63024dcffde6775ea37c92ab424d6dc98e-2880x1620.png?w=1440&q=95&auto=format&dpr=2)

### **Overview**[⁠](https://linear.app/docs/notion.html#overview)

The Notion integration embeds Linear issues, projects, initiatives, and views into Notion pages. They can be previewed in Notion or clicked to open in Linear.

### **Configure**[⁠](https://linear.app/docs/notion.html#configure)

Paste a link from Linear into Notion and follow the setup steps. Alternatively, Connect to Notion from within Linear under *[Settings > Features > Integrations > Notion](https://linear.app/settings/integrations/notion.html).* Each user in a workspace wishing to use this integration must set it up individually.

If desired, multiple Notion workspaces can be connected to the same Linear workspace.

### **Basics**[⁠](https://linear.app/docs/notion.html#basics)

**Embed files**

Simply copy a link to a Linear issue, project, initiative, or view and paste it into a Notion document. Choose whether to paste the link as a rich preview, a less detailed mention, or the raw URL.

**Open files**

Click the preview, mention or URL to open the associated data in Linear.

**Refreshing mentions and previews**

Once issue, project, or view properties change in Linear, the preview in Notion changes accordingly (on page reload or manual preview refresh). This integration is primarily for previewing Linear content in Notion and quickly opening it in Linear. It is not intended to support a full two-way workflow between the two tools.
