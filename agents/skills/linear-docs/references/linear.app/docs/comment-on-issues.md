# Comments and reactions

Leave comments or reactions on issues.

![comments and reactions on a Linear issue](https://webassets.linear.app/images/ornj730p/production/ec0d3a41ec497dbb27653e26110d8a3cac29b964-1203x796.png?w=1440&q=95&auto=format&dpr=2)

## Overview[⁠](https://linear.app/docs/comment-on-issues.html#overview)

Comments and reactions allow for team collaboration within an issue.

All users with access to an issue can post comments and threaded replies. React with emoji on the issue description itself, or on individual comments or threads.

## Post a comment[⁠](https://linear.app/docs/comment-on-issues.html#post-a-comment)

Comment on an issue by clicking into the “Leave a comment…” text box at the bottom of an issue. While issue description text is saved automatically, you will need to click the *Comment* button or `⌘/Ctrl`  `Enter` to post the comment to the issue. Unsent comments are visible on the issue, and in *Drafts* in your sidebar.

Attach files to a comment using the paperclip icon, `⌘/Ctrl` `Shift` `A`, or drag and drop.

The comment input also serves as the entry point for [Linear Agent](https://linear.app/docs/linear-agent.html#linear-agent-in-comments). Type `@Linear` in any comment field to invoke the agent in context — for example, to draft a status update, summarize the issue, or produce a list of action items ready to post.

## Edit or manage a comment[⁠](https://linear.app/docs/comment-on-issues.html#edit-or-manage-a-comment)

To edit an existing comment you wrote on an issue, click on the `...` icon to the top right of the comment and select `edit`. Click `save` to save any changes you make.

Other options in this menu allow you to manage your subscription to that thread, copy a URL to the comment, create a new issue or sub-issue from the comment, or delete the comment.

## Threads[⁠](https://linear.app/docs/comment-on-issues.html#threads)

![Thread comment on Linear issue](https://webassets.linear.app/images/ornj730p/production/b22cee655d066d6090a4e6bf6c1617516fc607eb-1104x326.png?w=1440&q=95&auto=format&dpr=2)

Threads allow you to continue on a topic mentioned in a comment. To create a threaded comment:

1. Hover over the comment you’d like to respond to
2. Click on the *arrow* icon for **Reply to comment** in the top right

If a thread already exists, click into the text box at the bottom of this comment thread and start crafting your response. Send threads as you would a regular comment.

### Resolve threads[⁠](https://linear.app/docs/comment-on-issues.html#resolve-threads)

Resolving threads clarifies when a question has been answered or a decision is made. This is particularly useful in longer threads to clearly identify the resolution.

Mark a thread as resolved through the overflow menu on the root message. To showcase a specific resolution, resolve a thread from a particular reply to expose that reply specifically.

With the setting [*Enable resolved thread AI summaries*](https://linear.app/docs/comment-on-issues.html#summaries-on-resolved-threads) enabled, AI will generate summaries for resolved comment threads.

## Summaries[⁠](https://linear.app/docs/comment-on-issues.html#summaries)

Get up to speed on long discussions with AI-generated summaries.

Available to workspaces on our [Business](https://linear.app/pricing.html) and [Enterprise](https://linear.app/pricing.html) plans.

## Emoji react to issues and comments[⁠](https://linear.app/docs/comment-on-issues.html#emoji-react-to-issues-and-comments)

You can add emoji reactions to issues, comments, project updates, and initiative updates.

All official Unicode emojis are available by default. Custom emojis can be uploaded individually (JPG, GIF, and PNG formats are supported).

## Inline comments on descriptions[⁠](https://linear.app/docs/comment-on-issues.html#inline-comments-on-descriptions)

To comment on a specific part of your description, highlight the text you want to comment on and from the formatting toolbar choose the comment icon or hit `⌘` ⌥ `M` (Mac), `CTRL Alt M` (Win) on your keyboard. Inline comments are also supported on documents, and project overviews.
