# Start Guide

Linear is the product development system for teams and agents. This guide helps you move quickly from new workspace to getting work done.

## Overview and demo[⁠](https://linear.app/docs/tutorials.html#overview-and-demo)

To learn Linear’s layout before signing up, explore our [demo workspace](https://linear.app/demo.html) to see how issues, projects, and workflows fit together.

If you’d prefer to walk through Linear live, consider joining an [onboarding session](https://luma.com/welcome-to-linear) to learn the essentials and see common workflows in action.

## Create a workspace[⁠](https://linear.app/docs/tutorials.html#create-a-workspace)

Once you’ve seen the basics, [create a workspace](https://linear.app/signup.html) using your work email to get started.
