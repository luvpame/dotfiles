# Effectively report an issue with embedded screenshots and videos

![Screenpresso interface showing Linear integration](https://webassets.linear.app/images/ornj730p/production/465bfb9b0de66294f462493939db9e8b2961de01-1500x960.png?q=95&auto=format&dpr=2)

![Screenpresso interface showing Linear integration](https://webassets.linear.app/images/ornj730p/production/465bfb9b0de66294f462493939db9e8b2961de01-1500x960.png?q=95&auto=format&dpr=2)

## Overview [⁠](https://linear.app/integrations/screenpresso.html#overview)

Using Screenpresso, you can take screenshots and annotate them, or record videos with the Webcam, then quickly create Linear issues with these captures embedded.

## How it works[⁠](https://linear.app/integrations/screenpresso.html#how-it-works)

Screenpresso is the best screen capture for Microsoft Windows. You can capture high quality images then annotate them using beautiful and useful drawing tools. You can also capture high resolution videos with the audio, webcam and zoom on specific areas.
Once this is done, simply click on the **Publish** button to create Linear issues. In the description field you can embed these captures at the right position.

## Configure[⁠](https://linear.app/integrations/screenpresso.html#configure)

Download Screenpresso from the official site: <https://www.screenpresso.com/download/>
Run the exe. It does not require to be installed and does not require administrator privileges.
Open the settings and link your Linear account with Screenpresso.
More details in this short Y[outube demonstration.](https://youtu.be/bbOOyFJtI6k)
