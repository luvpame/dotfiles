## Overview[⁠](https://linear.app/integrations/pipedream.html#overview)

Pipedream enables developers to build and run workflows integrating Linear with 700+ additional apps. You can use 1000s of open source triggers and actions or write custom code to integrate any app or API in seconds.

## How it works[⁠](https://linear.app/integrations/pipedream.html#how-it-works)

Pipedream provides a free, hosted platform for connecting apps and developing event-driven automations. The platform has over 700 fully-integrated applications, so you can use pre-built components to quickly connect to send messages to Slack, add a new row to Google Sheets, and more. You can also run any Node.js, Python, Golang, or Bash code when you need custom logic.

The current Linear integration supports the following triggers:

* New created issue
* New updated issue

The current Linear integration supports the following actions:

* Create an issue
* Search issues
* Update an issue
* Get teams
* Get an issue
