# Create new issues right from your browser command bar

![A screenshot of the Arc command line ](https://webassets.linear.app/images/ornj730p/production/1fcaa1bafa7d9664730d7e0b436cd08bb1a240b0-1500x960.png?q=95&auto=format&dpr=2)

## Overview[⁠](https://linear.app/integrations/arc.html#overview)

With this integration you can create new Linear issues directly from your Arc command bar.

## How it works[⁠](https://linear.app/integrations/arc.html#how-it-works)

In Arc, simply hit `⌘` `t` to open the command bar. Then type “New Linear issue” and press `Enter ⏎`. You will now see a new tab with Linear’s issue creation modal already open.

## Configure[⁠](https://linear.app/integrations/arc.html#configure)

This integration is pre-installed in Arc and doesn’t require any extra configuration.
