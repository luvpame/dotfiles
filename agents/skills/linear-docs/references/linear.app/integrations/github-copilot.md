## Overview[⁠](https://linear.app/integrations/github-copilot.html#overview)

You can now assign issues in Linear to GitHub Copilot coding agent, GitHub’s asynchronous, autonomous background agent.

When you assign a Linear issue to Copilot, it will:

1. Analyze the issue contents and open a draft pull request
2. Work independently in its own ephemeral development environment, powered by GitHub Actions. Within this environment, Copilot can explore your code, make changes, run automated tests and linters, and more.
3. Stream progress updates back to your Linear activity timeline
4. Request a pull request review from you when work is completed

## How it works[⁠](https://linear.app/integrations/github-copilot.html#how-it-works)

* Automate repetitive tasks like bug fixes, refactors, and documentation updates
* Reduce manual steps and context switching between Linear and GitHub
* Follow your existing review and approval rules for every pull request Copilot creates

## Configure[⁠](https://linear.app/integrations/github-copilot.html#configure)

1. Workspace admin [installs](https://gh.io/github-copilot-for-linear) the integration
2. Users must link their GitHub account to Linear in order to use the integration (users will be prompted to do this in the UI)
