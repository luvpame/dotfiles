## Overview[⁠](https://linear.app/integrations/github.html#overview)

Linear’s GitHub integration keeps your development workflow connected across both applications. You can link Linear issues to pull requests and commits, automate issue status based on PR activity, and review pull requests in Linear with [Diffs](https://linear.app/docs/pull-request-reviews.html).

The GitHub integration unlocks agentic coding features on Business and Enterprise plans. [Code Intelligence](https://linear.app/docs/code-intelligence.html) lets you use Linear agent to answer questions about your codebase when investigating issues. Or, share this ability widely so your GTM team can answer user product questions confidently. You can also automatically delegate incoming issues to Linear to start [coding sessions](https://linear.app/docs/coding-sessions.html) using Claude Code or Codex.

## Configure[⁠](https://linear.app/integrations/github.html#configure)

A Linear owner or admin with GitHub organization owner access can enable the GitHub integration in [Settings](https://linear.app/settings/integrations/github.html).

Once connected, members can link pull requests and commits and configure workflow automations. After configuring this integration, workspace admins can enable [Diffs](https://linear.app/docs/pull-request-reviews.html), as well as [Code Intelligence](https://linear.app/docs/code-intelligence.html) and [coding sessions](https://linear.app/docs/coding-sessions.html) on applicable plans.

Learn about [advanced configuration options](https://linear.app/docs/github.html#configure), including auto-link and connecting a [GitHub Enterprise Cloud account](https://linear.app/docs/github.html#github-enterprise). Linear also supports integrating with [GitHub Enterprise Server](https://linear.app/integrations/github-enterprise-server.html).

### Status automations[⁠](https://linear.app/integrations/github.html#status-automations)

Link PRs and commits to Linear issues by using the `issue ID` in the branch name or PR title. To link multiple PRs, or link issues after creating the PR, use magic words like “fixes” along with the `issue ID` in the PR description or commit message. This creates a link to the PR in the Linear issue and a linkback to Linear from the PR.

Workflow automations set at the team level automate issue statuses to align with their PR/commit status. Turn on a couple of personal preferences settings to enable personal GitHub automations that auto-assign issues and move them to *In Progress.*

### Reviews[⁠](https://linear.app/integrations/github.html#reviews)

Review and merge pull requests in Linear with native diffs and guided reviews that organize changes semantically. Comments, checks, and review activity are synced bi-directionally with GitHub. Learn more about [Linear Diffs](https://linear.app/docs/pull-request-reviews.html) in our documentation.

### Coding sessions[⁠](https://linear.app/integrations/github.html#coding-sessions)

Once GitHub is connected, you can enable coding sessions to support automatic issue delegation. When delegating to Linear, the agent starts a secure coding session through Claude Code or Codex to draft a PR. This feature draws from your [AI credits](https://linear.app/docs/ai-credits.html). Learn more in our [documentation](https://linear.app/docs/coding-sessions.html).

### Code Intelligence[⁠](https://linear.app/integrations/github.html#code-intelligence)

Code Intelligence gives Linear controlled access to your connected GitHub repositories, so teams across your organization can ask Linear Agent questions about your codebase like:

> What changed since our last desktop release that could cause this regression?

> How does the authentication system work?

Learn more about Code Intelligence in our [documentation](https://linear.app/docs/code-intelligence.html).

### GitHub Issues Sync[⁠](https://linear.app/integrations/github.html#github-issues-sync)

If you use GitHub Issues in open source repos you maintain, connect them to Linear so new GitHub issues are also created in Linear. Comments, status, labels and assignee sync bi-directionally.
