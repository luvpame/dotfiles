## Overview[⁠](https://linear.app/integrations/ponte-digital.html#overview)

Ponte Digital is a development service that works inside Linear. Assign an issue to it and you get back a pull request in your own repository, a preview link you can click through, and review notes in the same issue thread. Every change is built with AI agents and checked by a developer before you see it, so the review does not land on your own team.

## How it works[⁠](https://linear.app/integrations/ponte-digital.html#how-it-works)

Assign an issue to Ponte Digital, or mention it in a comment, and it reads the issue along with the context around it. If the request is clear it confirms what you will receive, in your own words, and starts work. If it is vague or too large for a single change, it asks about the parts that matter or proposes splitting it before anything is built, so nothing comes back as a surprise.

Work happens on a branch in your own repository through a GitHub App you install, and the change is deployed to a preview environment that points at non-production data. A developer then opens that preview, runs the change and checks it against what was agreed, releasing it only once it holds up. If something is missing along the way, you are asked on the same issue and the work resumes from where it stopped once you answer.

When the work is released you get the pull request, the preview link, the full diff and the review notes in the issue thread. You merge it yourself in your own repository, since Ponte Digital never pushes to your main branch and never holds your production secrets. You can ask questions about a delivered change or request an adjustment in the same thread, and each workspace has its own queue, so issues are worked one at a time in the order you choose.

## Configure[⁠](https://linear.app/integrations/ponte-digital.html#configure)

A Linear workspace admin installs Ponte Digital and chooses which teams it can access. An admin then accepts the terms in the Ponte Portal, and someone who owns your GitHub organization installs the Ponte Digital GitHub App on the repositories you want worked on. Each Linear team is connected to the repository its issues are built in, and each of those repositories needs a preview environment that deploys from a branch and points at non-production data. Ponte Digital is a paid monthly service, and once a plan is chosen you assign an issue to it by pressing A and selecting the app. The full walkthrough is in [Ponte Digital’s documentation](https://pontedigital.co/linear).
