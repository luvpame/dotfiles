## Overview[⁠](https://linear.app/integrations/flare.html#overview)

You can create a Linear issue directly from a Flare error and resolve an error when the Linear issue is closed.

## How it works[⁠](https://linear.app/integrations/flare.html#how-it-works)

Once the integration is set up, users can associate Flare errors with Linear issues directly within the Flare interface. Upon encountering an error, developers have the option to create a new Linear issue with a simple click, or link the error to an existing issue within Linear.

Flare automatically resolves errors when corresponding Linear issues are closed, and vice versa, ensuring synchronization between the two platforms. For users who prefer more control over these automations, customizable configuration options are available within project settings to tailor the integration’s functionality to specific needs and preferences.

## Configure[⁠](https://linear.app/integrations/flare.html#configure)

In Flare, go to Team settings > Linear , and click on the add a Linear connection button. After authorizing Linear, you can connect your project to a Linear team.
