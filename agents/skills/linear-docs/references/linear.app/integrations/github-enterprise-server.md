## Overview[⁠](https://linear.app/integrations/github-enterprise-server.html#overview)

*This integration is only meant for customers who self-host their GitHub Enterprise Server. For cloud-hosted GitHub Enterprise, please use GitHub enterprise Cloud.*

Link your GitHub pull requests with your Linear issues to keep your work in sync in both applications. Issues update automatically from *In Progress* to *Done* as the PR moves from drafted to merged – there is no need to update the issue in Linear at all.
