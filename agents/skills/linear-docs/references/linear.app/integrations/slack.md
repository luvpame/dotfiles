## Overview[⁠](https://linear.app/integrations/slack.html#overview)

The Slack integration makes it easy to create, update, and view Linear issues from Slack. Notifications and synced threads keep colleagues in the loop on projects and issues.

You must have a Linear account to use the Slack integration. Let any member of your Slack workspace send requests to Linear with [Linear Asks](https://linear.app/integrations/linear-asks.html).

## How it works[⁠](https://linear.app/integrations/slack.html#how-it-works)

Create Linear issues from Slack or ask questions about your workspace by mentioning @Linear.

You can also create issues using the message overflow menu in Slack.

When you create issues from Slack, the comment thread in Slack will be bidirectionally synced with a thread in the issue. This is particularly useful for keeping users reporting issues informed even if they don’t have a Linear account. In addition to syncing comments, the synced thread in Slack will be updated when the issue is completed or cancelled.

Links from Linear sent in Slack will expand to show a preview with key properties such as description, status, and assignee for issue links and description, status, and target dates for project links. Expanded links include actions when available so that members can update issues directly from Slack.

The integration offers several types of notifications for Slack. Enable personal notifications so that Inbox notifications also go to Slack. Team and project notifications can be directed to dedicated Slack channels to keep everyone in the company updated regardless of whether they have Linear accounts.

## Configure[⁠](https://linear.app/integrations/slack.html#configure)

Workspace admins (owners, on Enterprise) can configure this integration in [Settings](https://linear.app/settings/integrations/slack.html). Completing this step enables creating issues from Slack, message actions, and expandable links for every member of the workspace.

### Connect Linear’s MCP server to Slackbot[⁠](https://linear.app/integrations/slack.html#connect-linear's-mcp-server-to-slackbot)

You can connect Linear’s MCP server to Slackbot so it can access your Linear data when you ask it questions in Slack.

#### Setup[⁠](https://linear.app/integrations/slack.html#setup)

A Slack admin adds Linear as a custom MCP server in Slackbot’s connector settings. See [Slack’s documentation](https://slack.com/help/articles/52414744085139-Connect-Slackbot-to-other-apps-with-MCP) for more information about connecting an MCP server to the Slackbot.

#### Commonly used tools[⁠](https://linear.app/integrations/slack.html#commonly-used-tools)

Slackbot can call these tools, and more, to read and update Linear on your behalf:

* `list_issues` and `get_issue` — Find issues across your workspace, filtered by team, assignee, project, label, status, priority, or cycle.
* `save_issue` — Create a new issue or update an existing one — set the title, team, assignee, project, labels, priority, status, and more.
* `list_projects` and `get_project` — Browse projects in your workspace or pull a single project’s details, including milestones and members.
* `get_status_updates` — Read the latest status updates on a project or initiative to catch up on progress.
* `list_users` — Look up people in your workspace to find an assignee, lead, or owner.
