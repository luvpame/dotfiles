# Connect Jules to the Linear MCP server

![An illustration of the jules logo](https://webassets.linear.app/images/ornj730p/production/8a2cfe37c75a8484d1e6089e18613983b455b9d8-1500x960.png?q=95&auto=format&dpr=2)

![An illustration of the jules logo](https://webassets.linear.app/images/ornj730p/production/8a2cfe37c75a8484d1e6089e18613983b455b9d8-1500x960.png?q=95&auto=format&dpr=2)

### Overview[⁠](https://linear.app/integrations/jules-mcp.html#overview)

Jules is a coding agent that will research, code, test, and then submit changes for review. Connecting Linear’s MCP server lets the Jules inline agent open context from your issues or create new issues without leaving the IDE.

### Setup instructions[⁠](https://linear.app/integrations/jules-mcp.html#setup-instructions)

1. First in Linear, go to **Settings** > **Account** > [**Security & Access**](https://linear.app/settings/account/security.html)
2. Generate a new API key and copy it somewhere secure
3. Now in Jules, go to [**MCP Settings**](https://jules.google.com/settings/mcp)
4. Select **Connect** on the Linear server and paste your API key
5. Run a task invoking the server to confirm it works

*Remote MCP connections are still early and we’ve found that the connection may fail or require multiple attempts. If you experience issues, try restarting your client or disabling and re-enabling the Linear MCP server.*
