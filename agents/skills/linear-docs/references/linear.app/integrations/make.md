## Overview[⁠](https://linear.app/integrations/make.html#overview)

Make is a visual platform that lets you design, build, and automate anything in minutes — from simple tasks to complex workflows. It’s fast and easy to use, visually intuitive, and requires zero coding expertise.

## How it works[⁠](https://linear.app/integrations/make.html#how-it-works)

Make allows you to visually create, build, and automate workflows. Use the playful drag-and-drop interface to connect apps in a few clicks, and build limitless workflows called scenarios. Set your scenarios to run instantly or per schedule, or watch the scenario run in real time whenever you need.

Make includes conditional logic (if-then-else), iterators and aggregators, filtering error handling and inline functions. There’s literally no limit to the process you can build, from two-step automations to 100s or 1000s of steps. All possible without needing experience in programming languages.
