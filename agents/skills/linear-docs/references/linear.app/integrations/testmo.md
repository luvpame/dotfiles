## Overview[⁠](https://linear.app/integrations/testmo.html#overview)

Link test cases, test results, exploratory test sessions and test automation to Linear issues. Benefit from a complete DevOps workflow by combining Linear issue tracking with Testmo test management.

## How it works[⁠](https://linear.app/integrations/testmo.html#how-it-works)

Testmo is a unified test management tool that helps software and QA teams to manage all their testing activities in one modern platform. Track all your manual test cases, exploratory test sessions and test automation and integrate your testing workflow with Linear.

Testmo’s Linear integration makes it easy to link test cases, test results, exploratory test sessions and test automation to issues in Linear. Then quickly report on linked issues with coverage and defect reports and directly navigate to Linear to look up further issue details. Testmo also makes it easy to create new Linear issues during testing by providing useful links to your Linear projects.

Testmo was specifically designed to integrate with issue trackers: benefit from a complete DevOps workflow by combining Linear issue tracking with Testmo test management.

## Configure[⁠](https://linear.app/integrations/testmo.html#configure)

Enable and configure the Linear integration from Testmo under Admin > Integrations. You need to be a Project Admin or Site Admin in Testmo to access this section. Learn more in Testmo’s [integration documentation](https://docs.testmo.com/integrations/issue-trackers/linear).
