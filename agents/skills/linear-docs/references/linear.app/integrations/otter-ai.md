## Overview[⁠](https://linear.app/integrations/otter-ai.html#overview)

Connect [Otter.ai](https://otter.ai) to Linear Agent to bring meeting knowledge into your product and engineering workflow. Find customer feedback, recover decisions, and use meeting context to draft issues and project updates without copying transcripts between tools.

## How it works[⁠](https://linear.app/integrations/otter-ai.html#how-it-works)

Linear Agent connects to Otter’s hosted MCP server to search meetings and retrieve transcripts, summaries, action items, and attendees. Search by topic, date, or participant, then explore the relevant conversations in more detail.

Ask Linear Agent to summarize customer requests, identify commitments from planning meetings, or draft an issue from a discussion. Otter supplies the meeting context; Linear Agent uses it to help you work in Linear.

The connection uses OAuth and respects your Otter access permissions, including meetings shared with you. Access is authenticated to your Otter account, with no local MCP server to install.

## Configure[⁠](https://linear.app/integrations/otter-ai.html#configure)

In Linear Agent’s connector [settings](https://linear.app/settings/account/agents.html), add the MCP URL: <https://mcp.otter.ai/mcp> and sign in to your [Otter.ai](https://otter.ai) account. Once connected, ask Linear Agent to search your meetings and use that context in your work.
