## Overview[⁠](https://linear.app/integrations/aikido.html#overview)

Aikido Security is an all-in-one application security platform that gives you a full overview of all your security issues and shows you which security issues matter.

## How it works[⁠](https://linear.app/integrations/aikido.html#how-it-works)

Aikido Security helps you to secure your application by bringing together nine different security scanners in one platform. With the Aikido integration for Linear, you’re able to easily follow up on security work directly in Linear issues.

You can either fully automate the creation of issues in Linear or manually triage and select the issues in Aikido.

You can easily follow along the progress in Linear in Aikido’s Feed. For example to whom the ticket is assigned, and what the status is.

## Configure[⁠](https://linear.app/integrations/aikido.html#configure)

To get started for free, create an Aikido Security account and connect Linear with your workspace.

More details can be found on the [Aikido Security docs](https://help.aikido.dev/en/articles/8679657-setting-up-automated-task-creation-in-linear ).
