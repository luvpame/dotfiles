## Overview[⁠](https://linear.app/integrations/attio-agents.html#overview)

Connect Linear to Attio to intelligently search Linear issues, projects and comments using the context of your customer data.

## How it works[⁠](https://linear.app/integrations/attio-agents.html#how-it-works)

The Attio app for Linear helps you explore and reference your team’s work without leaving your GTM flow. Call the Linear MCP from a custom agent block in your Attio workflow and select exactly which tools to enable, giving you maximum control.

## Configure[⁠](https://linear.app/integrations/attio-agents.html#configure)

To get started go to <https://attio.com/apps/linear> and click the Install app button.
