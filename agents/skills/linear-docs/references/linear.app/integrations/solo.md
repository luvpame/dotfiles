![Tagging the AskSolo agent in Linear and getting a response](https://webassets.linear.app/images/ornj730p/production/d989f91037365438c5208ca6a9b19a746fe01b0d-2000x1280.png?q=95&auto=format&dpr=2)

![Tagging the AskSolo agent in Linear and getting a response](https://webassets.linear.app/images/ornj730p/production/d989f91037365438c5208ca6a9b19a746fe01b0d-2000x1280.png?q=95&auto=format&dpr=2)

## Overview[⁠](https://linear.app/integrations/solo.html#overview)

Solo analyzes your codebase and answers product functionality questions instantly in Linear.

## How it works[⁠](https://linear.app/integrations/solo.html#how-it-works)

Tag **@AskSolo** in any Linear issue and the agent will analyze the content and understand the full context of the conversation.
The agent will perform a search for the most relevant information across all your connected knowledge sources and reply with the answers on the Linear issue for you to review.

## Configure[⁠](https://linear.app/integrations/solo.html#configure)

To get started with the agent, follow the installation steps [here](https://help.asksolo.ai/en/articles/12754547-connect-with-linear).
