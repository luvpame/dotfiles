## Overview[⁠](https://linear.app/integrations/basedash.html#overview)

Basedash is an AI-native business intelligence platform. Teams connect Linear (and 750+ other sources) and ask questions in plain English. Basedash turns those into SQL-backed answers, dashboards, and scheduled reports. With Linear’s MCP server, the Basedash agent can also create and update issues from the same workspace, so analysis and follow-through live in one place.

## How it works[⁠](https://linear.app/integrations/basedash.html#how-it-works)

Connect Linear as a data source to sync issues, projects, cycles, comments, and related tables into Basedash Warehouse. From there, anyone on the team can ask questions like cycle throughput, lead time, or workload by team, save charts to dashboards, and schedule reports.

To take action, add Linear’s official MCP server as an MCP connector. The Basedash agent can then file bugs, update issues, and comment, with each tool gated to always-allow, needs-approval, or blocked.

## Configure[⁠](https://linear.app/integrations/basedash.html#configure)

**Analytics**
1. Log in to your Basedash workspace
2. Open Data in the sidebar
3. Select Add data source, search for Linear, and complete setup
4. Start asking questions, save charts to a dashboard, or schedule a report

**Issue workflows (MCP)**
1. Open Data in the sidebar and choose Add MCP server
2. Name it Linear and paste `https://mcp.linear.app/mcp`
3. Complete the Linear OAuth flow
4. Use chat or Automations to create or update issues. New tools default to needs approval.
