## Overview[⁠](https://linear.app/integrations/next.html#overview)

The NEXT x Linear integration facilitates the direct transfer of highlights, chats, and clusters into your backlog, allowing for the effortless transformation of insights into backlog items. Creating an issue in Linear (like a User Story or Bug) from NEXT automatically links to the supporting evidence (recordings and highlights), enabling your team to trace Linear items back to their origins.

## How it works[⁠](https://linear.app/integrations/next.html#how-it-works)

Users can select multiple NEXT highlights, and create a Linear issue from them. This will add the highlights as evidence to the newly generated Linear issue.

## Configure[⁠](https://linear.app/integrations/next.html#configure)

1. Open your teamspace in NEXT
2. Open settings via the top bar menu
3. Select “Integrations” section
4. Select integration provider “Linear”
5. Click [Connect]
6. Click [New connection]
7. Enter Linear workspace URL
