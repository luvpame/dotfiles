## Overview[⁠](https://linear.app/integrations/postman-agent-mode.html#overview)

Turn insights into actionable Linear issues with Postman Agent Mode.

Automatically create, update, and assign tasks from API test results, specs, customer feedback, and meeting notes using MCP. Reduce manual triage and keep your backlog accurate and up to date. Stay focused on building while Agent Mode handles the busywork.

## How it works[⁠](https://linear.app/integrations/postman-agent-mode.html#how-it-works)

When you connect Postman Agent Mode to Linear via MCP, you can manage your Linear workspace and issues seamlessly. Agent Mode can update statuses, create issues, assign owners, and retrieve context—all alongside your Postman collections and APIs.

As you work, Agent Mode syncs with Linear in real time through MCP. Attach details and keep tasks aligned with development progress without leaving the Agent Mode. This keeps your backlog accurate as you review notes, test APIs, and coordinate work.

All updates are reflected directly in Linear, ensuring teams can review progress in Linear or continue iterating in Postman Agent Mode. The integration connects issue management with development workflows, reducing manual effort and context switching.

## Configure[⁠](https://linear.app/integrations/postman-agent-mode.html#configure)

Linear MCP Server can be discovered and configured in multiple ways:

Once logged in to your Postman account you can navigate to our [MCP Server Catalog](https://www.postman.com/explore/mcp-servers). Select “Linear Remote MCP Server” and fork it to add to Agent Mode.

While using Agent Mode you can click on the setting toggle, select “Configure MCP Server” and navigate to Linear’s MCP Remote Server” and connect via OAuth.

You can prompt Agent Mode to search for Linear’s MCP Server to easily find and connect to your Postman Agent Mode instance.

Learn more about adding a MCP Server to Postman Agent Mode [here](https://learning.postman.com/docs/reference/postman-api/postman-mcp-server/postman-mcp-remote-server/?_pm_handover=eyJ1aWQiOiJQTS5NakF5TmkweE1DMHhObFF4TnpvME9Eb3dNUzQ1TXpCYSIsImlhdCI6MTc5MjE3NzkxMywiZXhwIjoxNzkyMTc4MjEzLCJhdWQiOiJsZWFybmluZy5wb3N0bWFuLmNvbSIsImlzcyI6Ind3dy5wb3N0bWFuLmNvbSJ9.8WyazzO8h6er4jJLDj-r-CCCR9NwyMwRye7kzUoEPtc).
