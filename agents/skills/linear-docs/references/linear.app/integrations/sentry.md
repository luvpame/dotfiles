Sentry exceptions are bi-directionally linked to Linear issues

## Overview[⁠](https://linear.app/integrations/sentry.html#overview)

Create Linear issues from Sentry exceptions, link exceptions to existing Linear issues, and automatically create issues from Sentry based on alerts.

## How it works[⁠](https://linear.app/integrations/sentry.html#how-it-works)

After enabling this integration, an option to create or link Linear issues will appear in the right sidebar when viewing a Sentry exception. Create a new Linear issue or search for existing issues to link them. Linked issues show up in the right sidebar in Sentry with key details and Linear issues include a link to the corresponding Sentry issue.

The integration also supports creating Linear issues automatically. Create a new Sentry alert or add a Linear action to an existing alert in Sentry under Alerts. Pair automated alerts with the app’s [Triage](https://linear.app/docs/triage.html) feature for a seamless review process.

## Configure[⁠](https://linear.app/integrations/sentry.html#configure)

Enable the integration in Linear from [workspace settings](https://linear.app/settings/integrations/sentry.html). This integration does not support creating or linking to issues in private teams.

Sentry is also available as an [MCP server](https://linear.app/docs/connect-mcp-servers-to-linear-agent.html#current-available-servers-that-can-be-connected-to:#available-servers) for use with Linear Agent
