## Overview[⁠](https://linear.app/integrations/descript.html#overview)

This integration embeds Descript share URLs into Linear issues, comments, and documents.

## How it works[⁠](https://linear.app/integrations/descript.html#how-it-works)

Paste any Descript share link into Linear’s Markdown editor. The app will turn the link into an embedded video automatically so that you can play it directly from the issue description, comment, or document.

## Configure[⁠](https://linear.app/integrations/descript.html#configure)

None required. Descript links automatically embed in the text editor.
