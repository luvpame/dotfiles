# Sync tasks and new comments between Coffee projects and Linear

![coffee tasks showing connection to Linear](https://webassets.linear.app/images/ornj730p/production/8e35174733f801c63a1ab9de37fb59309b8d9c7b-1600x1000.png?q=95&auto=format&dpr=2)

![coffee tasks showing connection to Linear](https://webassets.linear.app/images/ornj730p/production/8e35174733f801c63a1ab9de37fb59309b8d9c7b-1600x1000.png?q=95&auto=format&dpr=2)

## Overview[⁠](https://linear.app/integrations/coffee.html#overview)

Connect the work discussed in Coffee with the issues your team tracks in Linear. Map Coffee projects to Linear teams or projects and choose one-way or two-way sync for task titles, descriptions, due dates, and new comments.

## How it works[⁠](https://linear.app/integrations/coffee.html#how-it-works)

Each Coffee project can connect to a Linear team or project. Choose Coffee to Linear, Linear to Coffee, or two-way sync, then use Sync now to import or export existing tasks in that destination. New task activity follows the selected direction, and Linear webhooks bring issue updates and new comments into Coffee.

The integration syncs task titles, descriptions, due dates, and new comments. Workflow statuses, assignees, labels, and attachments are managed separately in each app. Existing comment history and subsequent comment edits are not imported.

Connections use Linear OAuth with read and write permissions. You can pause an individual project mapping or disconnect the integration. Disconnecting revokes authorization and leaves existing tasks in place.

## Configure[⁠](https://linear.app/integrations/coffee.html#configure)

In your Coffee workspace, open [Settings → Integrations → Linear](https://meetcoffee.ai/settings/integrations/details/linear) and select Connect. Choose your Linear workspace and authorize Coffee; Linear workspace policies may require administrator approval. Select a Linear destination and sync direction for each Coffee project, enable its mapping, and save changes. You must be a Coffee project owner or administrator. Select Sync now to include existing tasks. [Setup guide](https://meetcoffee.ai/support#linear).
