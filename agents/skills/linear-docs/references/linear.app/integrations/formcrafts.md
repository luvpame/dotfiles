# Create issues in Linear using powerful intake forms

![Formcrafts and Linear interface for creating issues](https://webassets.linear.app/images/ornj730p/production/452265186b113c6b7b705ba2096e61421e4c6440-1500x960.png?q=95&auto=format&dpr=2)

![Formcrafts and Linear interface for creating issues](https://webassets.linear.app/images/ornj730p/production/452265186b113c6b7b705ba2096e61421e4c6440-1500x960.png?q=95&auto=format&dpr=2)

## Overview[⁠](https://linear.app/integrations/formcrafts.html#overview)

Create customizable forms for bug reports, feature requests, or internal requests that create new Linear issues.

## How it works[⁠](https://linear.app/integrations/formcrafts.html#how-it-works)

Formcrafts allows you to create powerful and highly customizable intake forms such as bug report, customer support, feature requests, or internal issues.

By connecting with Linear you can turn new responses into issues in Linear with customizable title and description. You can also map other issue properties like due date, priority, labels, assignee, and issue status.

Share your intake forms using unique links, or embed them on your website or dashboard.

## Configure[⁠](https://linear.app/integrations/formcrafts.html#configure)

Create an account on [app.formcrafts.com](https://app.formcrafts.com/signup). Add a new form, either [using a template](https://formcrafts.com/form-templates) or from scratch. Add basic fields to your form, and then create a Linear workflow action to customize the issue properties.
