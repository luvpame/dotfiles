## Overview[⁠](https://linear.app/integrations/chatwoot.html#overview)

Seamlessly create Linear issues directly from Chatwoot conversations, ensuring customer feedback and bug reports are instantly actionable. You can also link existing issues to conversations for better context and a more efficient support-to-engineering workflow.

## How it works [⁠](https://linear.app/integrations/chatwoot.html#how-it-works)

If your team uses Linear to manage product development, integrating it with Chatwoot helps bridge the gap between customer support and engineering. This integration allows your support team to easily escalate issues, feature requests, or bugs to your product team without ever leaving the conversation view in Chatwoot.

From any conversation, you can create a new Linear issue with a title and description, automatically including a link back to the original thread for context. You can also link existing Linear issues to conversations, making it easier to track related discussions and follow up once the issue is resolved.

This setup improves collaboration and ensures that valuable customer insights don’t get lost between tools. For a full walkthrough on how to configure and use the integration, check out our guide: How to track issues and features with Linear integration.

## Configure[⁠](https://linear.app/integrations/chatwoot.html#configure)

To set up the Linear integration, navigate to Settings → Integrations → Linear within your Chatwoot account and click Configure. You’ll need to be an account administrator to access this section.

Click the Connect button to initiate the authorization flow. When prompted, review the requested permissions and click Authorize to link your Linear workspace with Chatwoot.

Once connected, you’ll be redirected back to Chatwoot, where you can immediately start creating or linking issues directly from your conversations. For a step-by-step walkthrough, visit the integration [setup guide.](https://chatwoot.help/hc/user-guide/articles/1739949089-how-to-track-issues-and-features-with-linear-integration)
