## Overview[⁠](https://linear.app/integrations/langsmith-agent-builder.html#overview)

LangSmith Agent Builder lets you create AI agents in natural language that use Linear. Turn a PRD or a Slack message into new issues, and generate Calendar events for key milestones. Or get a summary of issues sent to Notion, email, or Slack. Just describe the job, then Agent Builder builds an agent to accomplish the task.

## How it works[⁠](https://linear.app/integrations/langsmith-agent-builder.html#how-it-works)

LangSmith Agent Builder lets you build agents that work with Linear so they can create, update, assign, and delete issues on your behalf. Trigger Linear actions directly from chat, on a schedule, or from external events like Slack.

Agents are configured in natural language: you provide a short prompt, and Agent Builder determines the approach, selecting the right tools, generating instructions, and creating sub-agents when needed. As you iterate, you can give feedback and your agent learns using memory.

Agent Builder supports solo users and teams. You can share agents across your workspace so teammates can clone, customize, and reuse them.

## Configure[⁠](https://linear.app/integrations/langsmith-agent-builder.html#configure)

Connect your Linear account to Agent Builder when you add a Linear tool to your agent.
