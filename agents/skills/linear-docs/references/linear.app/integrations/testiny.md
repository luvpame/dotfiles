## Overview[⁠](https://linear.app/integrations/testiny.html#overview)

Create or link Linear issues from within Testiny to track defects or requirements during testing. Link the issues to test cases, test results, or test runs and view the issues in overviews or generated reports.

## How it works[⁠](https://linear.app/integrations/testiny.html#how-it-works)

Testiny is a powerful and modern test management software for both manual and automated tests. Manage test cases, results, and runs and integrate your software testing process with Linear.

Testiny integrates with Linear to connect defect and requirements management with your testing efforts. The integration with Linear allows users to create new issues from within Testiny, or to link existing Linear issues. Issues can be added as requirements or defects to test cases, test runs, or test results.

## Configure[⁠](https://linear.app/integrations/testiny.html#configure)

To configure your Linear integration, you need to have administration privileges and create a new integration in Testiny Settings > Integrations. For detailed instructions see Testiny’s [integration documentation.](https://www.testiny.io/docs/integrations/issue-trackers/linear)
