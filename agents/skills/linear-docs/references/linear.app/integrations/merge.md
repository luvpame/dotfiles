## Overview[⁠](https://linear.app/integrations/merge.html#overview)

Merge’s platform allows developers to add a Linear integration to their product much more quickly and cost-effectively than if they were to build the integration themselves. Merge normalizes the data synced from Linear’s API and gives developers a full suite of tools (logs, issue detection, etc.) to manage the integration.

## How it works[⁠](https://linear.app/integrations/merge.html#how-it-works)

Merge is a developer tool to embed customer-facing API integrations in your product right out of the box, without the need to configure each integration separately. With Merge’s Unified API, developers access one standardized data model to pull and post Ticketing data.

Merge also provides tools to manage integrations, with a robust dashboard that allows users to control the scope of data being synced through Merge, configure webhooks, troubleshoot and resolve issues such as expired API keys, and more, without the use of engineering resources.

Spare your developers hundreds of hours for each integration they build and maintain—your product team will thank you.

## Configure[⁠](https://linear.app/integrations/merge.html#configure)

Information on setting up Merge and configuring your Linear integration is available via our API documentation—check out the Get Started guide [here](https://docs.merge.dev/get-started/introduction/).
