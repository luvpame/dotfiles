## Overview[⁠](https://linear.app/integrations/discord.html#overview)

This integration connects your Linear workspace to your Discord server so that you can create issues from Discord. Additional features let you search for and then post a link to an existing issue as well as share a summary of your day’s work.

## How it works[⁠](https://linear.app/integrations/discord.html#how-it-works)

Create issues from Discord by typing the `/linear issue` command into any channel. Add the title, team, and set optional properties such as assignee and project. Discord messages can be linked to existing issues by taking the *Link Discord message* action while viewing or selecting an issue.

Use the `/linear search` command to look up issues by `issue ID` or words in the title, description, or comments. Select the issue to post a link to the channel with a rich preview showing key issue details.

At Linear, team members post a daily *wrap* of the work they completed, to keep others in the loop and share a quick summary of progress. This habit, especially helpful for remote teams, has been built into the Discord integration. Type `/linear wrap` into any channel to trigger the action, which will post a summary of Linear issues completed in the last 24 hours.

## Configure[⁠](https://linear.app/integrations/discord.html#configure)

A Linear admin must first enable the integration for the workspace in [settings](https://linear.app/settings/integrations/discord.html). Once they do, any Linear user can link their Discord account to Linear to use these commands in Discord.
