## Overview[⁠](https://linear.app/integrations/sanity-content-agent.html#overview)

Content Agent is Sanity’s editorial agent that knows how you operate. With the Linear integration, it’s also a member of your workspace: it gets delegated work, comments in-thread, and shows up in your views like anyone else on the team. Assign a content ticket to **@sanity**, and the Content Agent returns a draft, ready for approval, using the same governance already set in Sanity.

## How it works[⁠](https://linear.app/integrations/sanity-content-agent.html#how-it-works)

There are two ways to give Content Agent work:

1. Delegate a whole issue. Assign it to **@Sanity**. You remain the assignee and Sanity becomes the delegate, so ownership doesn’t move. The agent works the issue and posts back in-thread.
2. Mention **@Sanity** in a comment or the issue description to hand off in one piece: update the pricing page copy, translate a launch post, change the author across a set of articles, or find every document missing a description.

In both cases, the agent runs on your Sanity permissions and does its editorial work in drafts. Publishing is a separate step that takes your confirmation. Document history records who requested each action, your workspace’s agent guidance applies to every run, and delegated issues stay in My Issues.

## Configure[⁠](https://linear.app/integrations/sanity-content-agent.html#configure)

Install the Sanity app, then connect your Sanity account when the agent first prompts you and pick which studio to work with. Requires a Sanity project on Studio v5.1.0 or later with a deployed schema. Detailed steps: [Sanity documentation](https://sanity.io/docs/content-agent/content-agent-for-linear)
