## Overview[⁠](https://linear.app/integrations/figma-make.html#overview)

Access Linear issues, projects, and documents from Figma Make to generate working prototypes with relevant product context. As you iterate, easily create or update Linear issues and projects right from Figma, turning ideas into planned work.

## How it works[⁠](https://linear.app/integrations/figma-make.html#how-it-works)

Figma Make connects with the Linear MCP server, allowing it to read and write data directly from Linear.

Use the Linear connector in Make to help your teams align on what to build and bring your product ideas to life faster and more accurately.

While chatting with Figma Make, you can bring in Linear issues to build functional prototypes and push updates back to Linear to keep everything in sync.

## Configure[⁠](https://linear.app/integrations/figma-make.html#configure)

Each user needs to add and authenticate to the Linear MCP server in Figma Make.

1. From the Figma Make chat box, click + and select Connector.
2. Click Add next to the Linear MCP server.
3. Follow the prompts to authenticate through the OAuth flow.
4. Once connected, you can manage the Linear MCP server by clicking + in the Figma Make chat box, click Connectors, and select Linear.
5. Enable or disable the Linear MCP server itself, or individual tools within the MCP server.
