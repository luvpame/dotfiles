## Overview[⁠](https://linear.app/integrations/tally.html#overview)

If you use Linear to manage bugs, feature requests, or internal tasks, this integration helps you turn Tally forms submissions into Linear issues instantly. So no product feedback slips through the cracks.

## How it works[⁠](https://linear.app/integrations/tally.html#how-it-works)

Create Linear issues from Tally form submissions by selecting Linear in the integrations tab of your published Tally form. You can:

- Choose which workspace, team, and project issues are created in
- Map Tally form fields to your issue title and description
- Include response details in the issue body

## Configure[⁠](https://linear.app/integrations/tally.html#configure)

Anyone with a Linear and a free [Tally account](https://tally.so?ref=linear) can access the integration.
