## Overview[⁠](https://linear.app/integrations/capybara.html#overview)

Capybara bridges Jira with GitHub, Linear and Azure DevOps, streamlining support and development collaboration.

## How it works[⁠](https://linear.app/integrations/capybara.html#how-it-works)

The Capybara integration for Linear helps connect or create Linear issues to Jira tasks. Synchronise comments and statuses from Linear issues back to Jira to help solve customer’s problems across tools faster.

## Configure[⁠](https://linear.app/integrations/capybara.html#configure)

1. Install Jira app from the marketplace [here](https://marketplace.atlassian.com/apps/1236139/capybara-github-linear-azure-devops-for-jira-jsm).
2. Go to a Jira task or support request and open Capybara panel.
3. Click “Connect to Linear” and login into Linear.
