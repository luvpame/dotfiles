## Overview[⁠](https://linear.app/integrations/spades.html#overview)

Spades helps teams have engaging discussions around issues to help with breaking issues down, finding bottlenecks early, to keep work moving along at a healthy pace.

## How it works[⁠](https://linear.app/integrations/spades.html#how-it-works)

Spades is a modern, web-based pointing poker application designed specifically for development teams to streamline their story point estimation process.

The core functionality revolves around enabling teams to vote on story points through synchronized voting sessions. When a team member selects an issue to estimate, all participants can cast their votes simultaneously, with the application automatically calculating the median, average, highest, and lowest votes.The host can then select the most appropriate option to set the effort level directly in Linear without leaving the application.

Fetch unestimated issues directly from your Linear workspace, view full issue details including descriptions and comments, and set final estimates back to Linear with a single click after reaching team consensus. The real-time synchronization ensures that all participants see votes and issue changes instantly, while the host can navigate between issues and the entire team’s view updates live. Additionally, Spades includes AI-powered features that generate implementation questions and discussion starters to facilitate more productive estimation sessions.
