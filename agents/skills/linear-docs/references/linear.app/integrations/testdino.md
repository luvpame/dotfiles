## Overview[⁠](https://linear.app/integrations/testdino.html#overview)

The TestDino and Linear integration enables quick one-click bug filing from TestDino tests to Linear, streamlining issue tracking for software teams. It simplifies creating detailed, uniform bug tickets directly from test failures, improving triage efficiency.

## How it works[⁠](https://linear.app/integrations/testdino.html#how-it-works)

With TestDino, users can create Linear bug tickets directly from failed or flaky tests. The integration pre-fills rich bug fields such as workspace, team, issue type, priority, summary, detailed test context, failure reasons, relevant code snippets, recent test history, console output, and related links from the test run and CI environment. Users can review, edit, and submit the bug tickets from within TestDino, after which the bug is logged in Linear with confirmation and easy access for continued triage.

## Configure[⁠](https://linear.app/integrations/testdino.html#configure)

1. In TestDino’s Pro Plan, go to the [connect to Linear](https://app.testdino.com/connect/linear) page to install.
2. From a failed or flaky test in TestDino “TestRuns” page, select the option to create a Linear bug report, where you can adjust pre-filled fields if needed before finalizing the creation. Create the Issue on Linear.
3. After creating the issue, you receive confirmation with Linear’s internal ID and a direct link to view the issue in Linear for further work.

For more details, please check out the support [doc](https://docs.testdino.com/integrations/issue-tracking/linear/).
