## Overview[⁠](https://linear.app/integrations/currents.html#overview)

Currents connects your test results to Linear so failing tests become actionable issues in one click. Each issue is automatically filled with the git and failure context your team needs to triage and fix faster, no copy-pasting required.

## How it works[⁠](https://linear.app/integrations/currents.html#how-it-works)

Currents turns failing tests into Linear issues without leaving your dashboard. Create a new issue from a test failure, choosing the Linear team, project, and assignee, or link an existing issue when the problem is already tracked. Every issue is pre-filled with the git context and failure details (error messages, stack traces) needed to understand and reproduce the problem.

To keep things in sync, Currents marks tests that have linked Linear issues, so you can see at a glance which failures are already being handled. Connections are managed at the workspace level, with access tokens refreshed automatically and revoked on uninstall.

## Configure[⁠](https://linear.app/integrations/currents.html#configure)

1. A Currents org admin opens Project → [Integrations → Linear](https://docs.currents.dev/resources/integrations/linear) and clicks Connect.
2. A Linear workspace admin approves the OAuth installation. It is installed at the workspace level, so admin permissions are required.
3. Back in Currents, enable Linear per project under the same Integrations page.

Requirements: Currents organization admin to connect and configure, and a Linear workspace admin to approve the install. After setup, anyone on the project can create or link issues. Connecting, enabling or disabling per project, and disconnecting remain admin-only.
