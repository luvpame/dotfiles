## Overview[⁠](https://linear.app/integrations/test-management-by-testsigma.html#overview)

With the Test Management by Testsigma integration, you get access to AI agents that automatically detect a Linear cycle the second it starts, and generate automatable test cases from the Linear issues part of that cycle instantly.

You can also link Linear issues with generated test cases to enable end-to-end traceability from development to testing.

You must have a Linear account and a Test Management by Testsigma account to use this integration.

## How it works[⁠](https://linear.app/integrations/test-management-by-testsigma.html#how-it-works)

Connect Linear to Test Management by Testsigma using a webhook to link your workspace. With a linked workspace, when a new cycle begins in Linear, AI auto-detects it and generates test cases for all issues from that cycle.

Alternatively, you can also create test cases with AI for any specific Linear issue. Choose the issue, add a prompt, and watch the AI agent generate detailed, structured test cases in seconds.

Create test runs directly from those cases and execute them with Atto, the AI coworker. See AI run every step interactively, while you can pause, tweak the data, and rerun any time. You can also automate test execution and run multiple test cases in bulk with Testsigma’s automation platform and get the test results back into Test Management by Testsigma.

When a test fails, Atto generates a detailed summary with steps and auto-logs bugs in Linear, complete with steps to reproduce and acceptance criteria. This integration keeps QA perfectly aligned with your Linear cycles, with test cases and results linked to their respective issues for end-to-end traceability.

## Configure[⁠](https://linear.app/integrations/test-management-by-testsigma.html#configure)

Sign in to [Testsigma](https://app.testsigma.com) or [create your free Test Management by Testsigma account](https://testsigma.com/tms-signup) (you’ll need this to set up the workspace). Linear admins can create [webhooks in Linear](https://linear.app/developers/webhooks.html) to enable real-time sync between both tools.

Once done, you can create a project in Test Management by Testsigma and connect it with the Linear project. Completing this step enables auto-detection of Linear cycles and instant test case generation from respective issues.
