### Overview[⁠](https://linear.app/integrations/linear-asks.html#overview)

Linear Asks gives organizations a powerful tool to manage common workplace requests. Once enabled, anyone can create an Ask to send their request to the relevant Linear team—even if they don’t have a Linear account—via Slack or email.

### Asks for Slack[⁠](https://linear.app/integrations/linear-asks.html#asks-for-slack)

In Slack, anyone in workspace can turn requests into actionable issues in Linear—even if they don’t have a Linear account. Create Asks directly or use the 🎫 :ticket: emoji to turn messages into Asks.

Requests can be fully managed from Slack; get immediate notifications when Asks are completed ✅ and reply to the Slack thread with questions or updates.

Asks are routed to the relevant team in Linear. Review, prioritize, assign, and update each issue without ever switching back to Slack.

### Asks for Email[⁠](https://linear.app/integrations/linear-asks.html#asks-for-email)

Set up a custom email address (e.g., `helpdesk@acme.com`) to automatically forward messages to a unique Linear intake address.

Each email received will create a new Linear issue, using the email subject as the issue title and the message body as the description. Senders will receive a confirmation email letting them know any replies they send will be synced to the same Linear issue.

A synced thread will be visible within the Linear issue. Teams can reply to the original email directly from this thread and view any incoming responses as they arrive.

### Configure[⁠](https://linear.app/integrations/linear-asks.html#configure)

Admins on Business and Enterprise plans can enable the integration in Linear from [settings](https://linear.app/settings/asks.html). Try Asks and other Business features for 30 days with a free trial.
