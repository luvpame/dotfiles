## Overview[⁠](https://linear.app/integrations/rootly.html#overview)

Rootly is the AI-native on-call and incident management platform that helps you resolve incidents faster, improve system resilience, and streamline on-call operations. It’s your always-on SRE copilot that automates root cause analysis and identifies patterns that drive continuous improvement—trusted by thousands of companies like LinkedIn, NVIDIA, Replit, Elastic, Canva, Clay, Tripadvisor, and Grammarly.

## How it works[⁠](https://linear.app/integrations/rootly.html#how-it-works)

With Rootly and Linear installed, customers can automatically:

* Create a Linear issue when a new incident is created with relevant metadata
* Create a Linear sub-issue when a new action item is created
* Update an issue ticket to *Done* when an incident is resolved

## Configure[⁠](https://linear.app/integrations/rootly.html#configure)

Enable the integration in two steps:

1. Go to [Rootly](https://rootly.com/users/sign_up) and then Integrations > Linear > Setup > Authenticate
2. Then navigate to *Workflows > Create Linear ticket* *(pre-populated)* and finish configuration
