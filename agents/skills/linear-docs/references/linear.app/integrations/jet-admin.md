## Overview[⁠](https://linear.app/integrations/jet-admin.html#overview)

Jet Admin integrates with Linear to help you build custom dashboards and internal tools for managing issues, projects, and cycles — all without coding.

## How it works[⁠](https://linear.app/integrations/jet-admin.html#how-it-works)

Create an app and simply connect Linear to Jet Admin to start the no-code building experience.
You can build apps to track progress, filter tasks, update statuses or create new issues through intuitive, drag-and-drop pages builder.
Automations let you trigger notifications, assign tasks, or sync data across tools, while permissions ensure secure, role-based access for your team.
