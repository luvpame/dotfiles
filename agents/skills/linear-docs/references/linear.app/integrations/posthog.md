## Overview[⁠](https://linear.app/integrations/posthog.html#overview)

Create Linear issues from PostHog, maintaining bi-directional links between the two.

## How it works[⁠](https://linear.app/integrations/posthog.html#how-it-works)

After enabling this integration, an option to create Linear issues will appear in the right sidebar when viewing a PostHog issue. Creating a new Linear issue allows you to assign it to a chosen team. Linked issues show up in the right sidebar in PostHog and Linear issues include a link back to the corresponding PostHog issue.

## Configure[⁠](https://linear.app/integrations/posthog.html#configure)

Enable the integration in PostHog from your [project settings](https://app.posthog.com/settings/project#integration-error-tracking). This integration does not support creating issues in private teams.

Posthog is also available as an [MCP server](https://linear.app/docs/connect-mcp-servers-to-linear-agent.html) for use with Linear Agent
