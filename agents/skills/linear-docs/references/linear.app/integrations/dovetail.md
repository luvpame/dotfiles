## Overview[⁠](https://linear.app/integrations/dovetail.html#overview)

Create Linear issues directly from customer intelligence in Dovetail. Turn feedback, user data, and customer findings into actionable tasks with full context attached.

## How it works[⁠](https://linear.app/integrations/dovetail.html#how-it-works)

Create Linear issues from any insight, highlight, theme, or data point in Dovetail. This integration allows users to include customer context directly on issues for their product team to view without needing to leave Linear, allowing them to understand exactly what users are saying.

Once an object from Dovetail is linked to an issue, it will appear as an interactive attachment within the Linear issue or project. The attachment contains the content from Dovetail and a direct link back for full context.

## Configure[⁠](https://linear.app/integrations/dovetail.html#configure)

You need a Dovetail account and a seat in Linear to set up this integration. In your Dovetail workspace settings, go to “Integrations” and click “Connect” next to Linear.

Sign in to Linear and approve the connection. The integration needs permission to create issues and read team information. Once connected, users can create Linear issues from the meatball menu (•••) on any insight, highlight, theme summary, or data point in Dovetail.
