Embed a rich YouTube player directly in issue descriptions and comments

## Overview[⁠](https://linear.app/integrations/youtube.html#overview)

This integration embeds YouTube videos into Linear issues, comments, and documents.

## How it works[⁠](https://linear.app/integrations/youtube.html#how-it-works)

Paste any YouTube link into Linear’s Markdown editor. The app will turn the link into an embedded video automatically so that you can play it directly from the issue description, comment, or document.

## Configure[⁠](https://linear.app/integrations/youtube.html#configure)

None required. YouTube links automatically embed in the text editor.
