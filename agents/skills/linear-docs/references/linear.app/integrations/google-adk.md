## Overview[⁠](https://linear.app/integrations/google-adk.html#overview)

Agent Development Kit (ADK) is a flexible and modular framework for developing and deploying AI agents. While optimized for Gemini and the Google ecosystem, ADK is model-agnostic, deployment-agnostic, and is built for compatibility with other frameworks.

## How it works[⁠](https://linear.app/integrations/google-adk.html#how-it-works)

Use Linear’s MCP server to connect your ADK agents to Linear so they can take actions in your workspace. Create and update issues, projects, documents and other objects.
