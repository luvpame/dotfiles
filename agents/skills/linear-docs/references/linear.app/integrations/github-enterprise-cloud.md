Pull Requests are bi-directionally linked to Linear issues

Connect Linear to GitHub Enterprise Cloud by providing your unique `ghe.com` domain.

Only setup differs between this integration and our standard GitHub integration. Once connected, functionality like linking PRs to issues, automating issue status changes, and syncing GitHub issues to Linear teams works identically. Learn more about general integration functionality [here](https://linear.app/docs/github.html#overview).
GitHub Enterprise Cloud is available on the Enterprise plan only.
