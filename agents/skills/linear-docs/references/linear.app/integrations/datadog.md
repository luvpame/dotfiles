# Create Linear issues from Datadog Cases and Monitors

![Comments and description synced between a datadog monitor and a linear issue](https://webassets.linear.app/images/ornj730p/production/a98d3b5d1338ce8d5d28ef2b3e7d563ed1548242-3000x1800.png?q=95&auto=format&dpr=2)

## Overview[⁠](https://linear.app/integrations/datadog.html#overview)

Linear’s Datadog integration allows you to create Linear issues directly from Datadog Cases and Monitors, bringing native observability context into Linear.

## How it works[⁠](https://linear.app/integrations/datadog.html#how-it-works)

The integration enables teams to seamlessly manage their work across Datadog and Linear. Once installed from the Linear integration tile within Datadog and authorized through Linear, you can create Linear issues directly from Datadog Monitor alerts or Cases.

### Create issues from Datadog Monitors[⁠](https://linear.app/integrations/datadog.html#create-issues-from-datadog-monitors)

With the integration, you can manage Monitor alerts directly from Linear. You configure issue templates that define how your alert data is translated into Linear issues. Templates can include teams, projects, assignees, and labels. You can also choose to comment on or transition issues when a Monitor resolves. Once configured, these templates can be referenced in Monitors using handles like @linear-my-template to automatically generate issues when alerts trigger.

### Create issues from Datadog Cases[⁠](https://linear.app/integrations/datadog.html#create-issues-from-datadog-cases)

Case Management is Datadog’s ticketing tool. With the integration, you can automatically create issues from Datadog Cases. You can also set up bi-directional syncing between Linear and Datadog to ensure that issues and Cases stay in sync without any manual updates. New comments and updates to the title, description, assignee, status, and priority will be reflected both ways.

## Configure[⁠](https://linear.app/integrations/datadog.html#configure)

For configuration information, refer to the instructions [here](https://docs.datadoghq.com/integrations/linear/). To authorize the integration within Datadog, you must be a Linear admin.

Datadog is also available as an [MCP server](https://linear.app/docs/connect-mcp-servers-to-linear-agent.html) for use with Linear Agent.
