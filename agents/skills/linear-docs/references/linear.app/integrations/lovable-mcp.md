## Overview[⁠](https://linear.app/integrations/lovable-mcp.html#overview)

Spin up and iterate on full-stack apps from your AI client using Linear context. Connect to the Lovable MCP server to create projects, send build instructions, review diffs, and deploy live apps, all driven by natural language alongside your Linear work.

## How it works[⁠](https://linear.app/integrations/lovable-mcp.html#how-it-works)

Lovable exposes itself as an MCP server, so a supported agent can create projects, send messages to Lovable, inspect code, and deploy apps without leaving the client you’re already in.

Describe what you want to build and Lovable’s agent does the work, returning a preview URL you can keep refining. Combine it with Linear in a single agent session: turn an issue or spec into a working app, then ship it and hand the live URL back to your team.

## Configure[⁠](https://linear.app/integrations/lovable-mcp.html#configure)

The Lovable MCP server uses OAuth. Add it in your supported client and authenticate with your Lovable account.
- Open your client’s connector or MCP settings.
- Add a custom MCP server with the URL https://mcp.lovable.dev.
- Complete the OAuth flow when prompted to sign in to Lovable.
- The Lovable tools appear in your client’s tool list once connected.

Supported clients: ChatGPT, Claude, Claude Code, Cursor, and VS Code.
