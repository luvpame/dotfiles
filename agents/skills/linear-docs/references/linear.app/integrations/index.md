## Overview[⁠](https://linear.app/integrations/index.html#overview)

Index’s Linear integration enables new planning and discovery capabilities for Product Management, and is the first alternative to Productboard and Jira Product Discovery that connects to Linear.

Create and connect Linear projects and view their issues from the Index app. Run planning, prioritization, and discovery in the only whiteboard for Linear, with spreadsheet and board views also available. Dates and status will automatically stay in sync between both tools for a connected discovery and planning experience.

## How it works[⁠](https://linear.app/integrations/index.html#how-it-works)

When you create a project in Index, you’ll have the option to push it to Linear, which will automatically create and connect the corresponding Linear project. New ideas which you’re still shaping can stay in Index until you’re ready. This enables the following workflows:

* Brainstorming new ideas with your team on a whiteboard, and pushing it to Linear when complete
* Managing customer requests in a spreadsheet with custom fields, and viewing the Linear status
* Running prioritization exercises in frameworks like RICE and WSJF on your Linear project list

Additionally, when visiting a project page in Index, you’ll be able to view the list of issues in Linear, along with the owner and status for each issue. You can click on any issue to jump to it in the Linear app.

## Configure[⁠](https://linear.app/integrations/index.html#configure)

To get started, go to Index’s [Linear integration page](https://index.inc/linear) and proceed through the CTA to add the integration. If you’re migrating from an alternative app like Productboard or Jira Product Discovery, you’ll be prompted to import your data so you can use it with Index and Linear.
