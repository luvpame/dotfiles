## Overview[⁠](https://linear.app/integrations/superconductor.html#overview)

Assign any Linear issue to Superconductor and your choice of coding agent gets to work in its own cloud sandbox. When it’s done, you get a live preview of the running app alongside the PR, so you can click through the change right from Linear. Teammates can jump into the same agent session to steer it or ask follow-up questions.

## How it works[⁠](https://linear.app/integrations/superconductor.html#how-it-works)

Once Linear is connected, you can assign any issue to Superconductor or mention **@Superconductor** in a comment with instructions. A coding agent starts working on it with the issue’s details as context, using your default agent or one you pick in the comment, like **@Superconductor** model:opus. Claude Code, Codex, Cursor and other agents are supported through your team’s existing subscriptions or API keys.

Each agent runs in its own cloud sandbox with your app’s development environment, so it can run the app and its tests as it works. When it finishes, you get a live preview of the running app and screenshots of the change, so you can check the result before reviewing the code. Teammates can open the same session in Superconductor to chat with the agent or go through the diff.

Superconductor posts progress in a thread on the issue. When the agent is done, it replies with a summary and links to the preview and the pull request, and posts again when the PR is merged. Reply in the thread to give feedback or ask follow-up questions, or stop the agent from there.

## Configure[⁠](https://linear.app/integrations/superconductor.html#configure)

A Superconductor workspace Owner or Admin can install the app from [Workspace Settings → Linear](https://www.superconductor.com/workspaces/default/integrations/linear), and a Linear workspace admin needs to approve it. Teammates don’t need to do any setup: anyone whose Linear email matches a member of your Superconductor workspace can assign or mention Superconductor on issues. You can optionally set a default Superconductor project for each Linear team on the same settings page. Detailed steps are in [Superconductor’s documentation](https://www.superconductor.com/docs/integrations/linear).
