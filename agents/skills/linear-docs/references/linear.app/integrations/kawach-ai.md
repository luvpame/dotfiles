## Overview[⁠](https://linear.app/integrations/kawach-ai.html#overview)

The Kawach.AI integration continuously monitors the Linear workspace to ensure that only entitled users have access to the workspace as per the organization’s access policies.

## How it works[⁠](https://linear.app/integrations/kawach-ai.html#how-it-works)

Kawach.AI is a GRC platform that continuously monitors the compliance with various controls and policies of the organization and flags any non-compliance. This can then later be also presented as an evidence during reviews and audits.

The integration of Kawach with Linear currently monitors the access of organizational users to Linear workspace, and ensures that only entitled users have access. If any user is no longer associated with the organization or his role has changed such that it warrants deactivation of the Linear account, it is flagged to the organization admin.

This compliance record is logged and can be periodically reviewed and audited.

## Configure[⁠](https://linear.app/integrations/kawach-ai.html#configure)

The user will need to be a Kawach admin to be able to integrate their Linear workspace with Kawach. More details can be found [here](https://support.kawach.ai/articles/linear).
