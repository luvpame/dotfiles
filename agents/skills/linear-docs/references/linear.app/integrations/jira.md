Jira issues are bi-directionally linked to Linear issues

## Overview[⁠](https://linear.app/integrations/jira.html#overview)

If you want to switch from Jira to Linear, this integration makes the process smoother by keeping projects up to date in Jira as you use Linear.

## How it works[⁠](https://linear.app/integrations/jira.html#how-it-works)

This integration keeps Jira up to date while your company trials or transitions to Linear.

First, you’ll connect specific Jira projects to Linear teams. New issues created in either service will create a synced copy in the other, with properties that sync bidirectionally. A synced comment thread in Linear will allow users to communicate back to the comment thread in Jira. For further details on the integration, please see our [documentation](https://linear.app/docs/jira.html).

Once you’re ready to make the switch, use Linear’s quick Jira importer to move over all your existing issues in a few minutes.

## Configure[⁠](https://linear.app/integrations/jira.html#configure)

A Linear admin can go to [settings](https://linear.app/settings/integrations/jira.html) to enable this integration, then link Jira projects to their corresponding teams in Linear. Configuration also requires ADMINISTER [permission](https://support.atlassian.com/jira-cloud-administration/docs/manage-global-permissions/) in Jira so that Linear can install the required webhooks.

This integration is designed to work with newly created issues. For existing tickets, import those to Linear in a few minutes using our Issue Migration Assistant.
