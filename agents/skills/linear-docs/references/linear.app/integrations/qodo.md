## Overview[⁠](https://linear.app/integrations/qodo.html#overview)

Qodo is an agentic AI-driven software development platform designed for complex enterprise software. Qodo AI works seamlessly with developers in their favorite tools across the entire SDLC. Available in popular IDEs, Git providers, CI/CD platforms, and project management tools like Linear,

Qodo combines capabilities in code generation, code review, and codebase understanding to solve real-world software development challenges—augmenting human developers and fully automating end-to-end tasks with customizable background agents.

## How it works[⁠](https://linear.app/integrations/qodo.html#how-it-works)

The Qodo integration with Linear automatically reviews pull requests and verifies compliance with business requirements defined in your Linear issues. It surfaces implementation gaps and identifies areas requiring further review.

With the Linear integration enabled, every pull request is reviewed for compliance with business requirements defined in the associated Linear issue. Qodo automatically identifies issue IDs in branch names or PR descriptions and associates them with the pull request. Requirements in the issue are then categorized as fully compliant, partially compliant, or requiring further verification.

PRs without linked issues can also be configured to automatically infer requirements from code behavior, ensuring proper documentation and compliance with security and privacy frameworks such as SOC 2 and ISO 27001.

## Configure[⁠](https://linear.app/integrations/qodo.html#configure)

To use the Qodo integration, you must have a Qodo account. Navigate to
[Qodo](https://www.qodo.ai), sign in to the Qodo admin portal, and find the integrations page to authenticate and connect to Linear. Learn [more](https://qodo-merge-docs.qodo.ai/core-abilities/fetching_ticket_context/?h=linear#linear-integration).
