# Delegate any issue to [code]smith

![Linear issue view with codesmith agent](https://webassets.linear.app/images/ornj730p/production/da76e0e3ed55cd2aabbde441f3e234a6e60c9645-1500x960.png?q=95&auto=format&dpr=2)

![Linear issue view with codesmith agent](https://webassets.linear.app/images/ornj730p/production/da76e0e3ed55cd2aabbde441f3e234a6e60c9645-1500x960.png?q=95&auto=format&dpr=2)

## Overview[⁠](https://linear.app/integrations/codesmith.html#overview)

[code]smith is a coding agent from Blacksmith. Tag @codesmith on an issue or assign it an issue directly to spin up a cloud agent to work on a task. [code]smith automatically runs CI, testing and QAing the change as it works and pushing evidence back to show the change’s impact.

## How it works[⁠](https://linear.app/integrations/codesmith.html#how-it-works)

[code]smith works across repositories, using its code index to select the right repository for a change. Its integration with Blacksmith testboxes lets it run CI against its changes, spinning up a machine and taking screenshots and videos of its work.

Whether validating a change from another agent or pushing an entire feature, [code]smith writes better code, faster.

## Configure[⁠](https://linear.app/integrations/codesmith.html#configure)

Sign up for Blacksmith at [app.blacksmith.sh](https://app.blacksmith.sh), authorize the GitHub app, and start building. Once connected, follow Linear’s instructions for adding a new agent, then @mention or assign [code]smith on any issue to see the resulting pull request.
