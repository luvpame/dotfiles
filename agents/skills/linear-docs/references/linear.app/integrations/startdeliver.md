## Overview[⁠](https://linear.app/integrations/startdeliver.html#overview)

This integration will streamline your workflow, enhances collaboration between customer success and development teams and provide a unified view of customer-related progress across Startdeliver and Linear.

## How it works[⁠](https://linear.app/integrations/startdeliver.html#how-it-works)

**Task Creation and Assignment**

* Create customer-related tasks in Startdeliver
* Assign tasks to specific Linear teams for development or support
* Automatic task synchronization from Startdeliver to Linear

**Bi-Directional Comment Syncing**

* Comments made in Startdeliver are reflected in Linear
* Comments made in Linear are mirrored in Startdeliver
* Real-time updates ensure customer success and development teams are always aligned

**State Synchronization**

* Linear push task state changes back to Startdeliver
* Allows for real-time progress tracking in both platforms

**Unified Workflow**

* Maintain a single source of truth for customer-related task status
* Reduce context switching between platforms
* Improve coordination between customer success and development teams

## Configure[⁠](https://linear.app/integrations/startdeliver.html#configure)

You need to be an admin in Startdeliver and Linear to authenticate the integration. Once the app is added to your Startdeliver account, go to Settings and click to start authentication. You will be redirected to Linear to approve the integration.
