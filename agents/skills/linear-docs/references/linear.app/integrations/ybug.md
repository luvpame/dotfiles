# Turn visual website feedback into ready-to-triage Linear issues

![Turn visual feedback into ready-to-triage Linear issues](https://webassets.linear.app/images/ornj730p/production/9e22a48a5473ae3bababca7196126ba92c6cfa73-1500x960.png?q=95&auto=format&dpr=2)

## Overview[⁠](https://linear.app/integrations/ybug.html#overview)

Collect website feedback with Ybug and turn it into ready-to-triage Linear issues.

Reporters can point, click, annotate, and send feedback from your site, while Ybug adds the screenshot or recording, page URL, browser details, and console logs so developers get the full picture from the start.

## How it works[⁠](https://linear.app/integrations/ybug.html#how-it-works)

Ybug adds a visual feedback widget to your website or web app. When someone spots a bug, they can mark up the page, record what happened, and describe the issue in their own words. In the background, Ybug captures the practical details developers usually need: URL, browser and OS, viewport size, and JavaScript console logs.

The Linear integration turns each selected Ybug report into a new Linear issue. The issue includes the reporter’s note, links to the annotated screenshot or screen recording, technical context, console output when available, and a link back to the full report in Ybug. Less copy-paste, fewer contextless tickets.

You can send reports to Linear automatically as they arrive, or review them in Ybug first and push only the ones worth tracking. Each Ybug project connects to one Linear team, with optional project, workflow status, labels, and default assignee settings, so feedback lands in the right place from the start.

## Configure[⁠](https://linear.app/integrations/ybug.html#configure)

[Sign up for Ybug first](https://app.ybug.io/signup), create a project, and install the Ybug feedback widget on your website or web app. Once the widget is live, Ybug can collect feedback with screenshots, recordings, comments, and technical context, then send selected reports to Linear.

In Ybug, open the project you want to connect, go to Project *Settings* > *Integrations*, and enable Linear. Ybug will send you to Linear to authorize the connection with OAuth, then bring you back to finish setup.

Choose the Linear team where new issues should be created. You can also set an optional project, workflow status, labels, and default assignee. Save the integration, then choose whether reports should go to Linear automatically or be reviewed in Ybug first.
