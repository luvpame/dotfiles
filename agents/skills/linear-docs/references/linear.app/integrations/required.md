## Overview[⁠](https://linear.app/integrations/required.html#overview)

This integration is an addon for Linear that allows users to define required fields that must be filled before moving issues to different states in the workflow. This ensures that all necessary data is completed, helping users avoid mistakes and maintain the integrity of their project management process.

## How it works[⁠](https://linear.app/integrations/required.html#how-it-works)

This integration serves as a powerful add-on for Linear, enabling users to define specific fields that must be completed before an issue can transition to another state in the workflow. By setting these required fields, teams can ensure that all necessary information is captured, which helps maintain data integrity and reduces the likelihood of errors during project management. This functionality is particularly beneficial in complex projects where oversight can lead to significant setbacks.

When a user attempts to move an issue to a different state and a required field is missing, the integration automatically reverts the issue back to its previous state. Additionally, it comments on the issue to inform the user about the missing information. This mechanism not only streamlines the workflow but also encourages team members to provide complete and accurate data, fostering a culture of accountability and thoroughness.

The integration offers customizable settings, allowing teams to define which fields are required for each state in their workflow. This flexibility ensures that the integration can adapt to various project needs and team structures. By implementing this addon, users can enhance their project management processes, ensuring that all critical information is captured before moving forward, ultimately leading to more successful project outcomes.

## Configure[⁠](https://linear.app/integrations/required.html#configure)

To get started with the integration, users must first sign up for an account and connect their Linear workspace from an Admin account.

Once connected, you can set up the required fields that must be filled before moving issues to different states in the Linear workflow. This setup involves specifying which fields are mandatory and determining the states in which these fields must be present, allowing for a tailored workflow that meets the team’s specific needs.
