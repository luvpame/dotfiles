## Overview[⁠](https://linear.app/integrations/ranger.html#overview)

Ranger transforms bug issues into clear and consistent formatting and generates test plans for feature work in seconds.

## How it works[⁠](https://linear.app/integrations/ranger.html#how-it-works)

To take action on a bug, tag **@ranger** in a comment and it will update the title and description of your issue to clarify and enforce consistent formatting. To make tweaks and changes, just reply to **@ranger** in the comments until you’re happy with the end result.

To test a new feature, ask **@ranger** to generate a test plan. This plan can be shared with a QA team member to help document how to confirm the feature is working as expected. If the test plan is not as desired or is missing detail, simply reply to the comment to provide additional context and **@ranger** will work to produce your desired test plan.

Not sure what Ranger can do? You can always ***@ranger** help* in a comment to get more insight into Ranger’s capabilities.

## Configure[⁠](https://linear.app/integrations/ranger.html#configure)

To set up Ranger, just install the app [here.](https://ranger.net/linear) Once installed, mention **@ranger** in a comment to get help with any issue.
