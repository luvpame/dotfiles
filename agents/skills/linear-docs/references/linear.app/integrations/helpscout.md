## Overview[⁠](https://linear.app/integrations/helpscout.html#overview)

Get all the info you need within a customer conversation — no more switching between tabs or systems. This integration makes it easy to link, track, and create new issues in Linear, right in Help Scout.

## How it works[⁠](https://linear.app/integrations/helpscout.html#how-it-works)

When viewing a Help Scout conversation, you can see at a glance whether that conversation is linked to any Linear issues and what their current status is. Click on a linked issue to open a detail view a full issue description and the current assignee right in the sidebar or open the issue in Linear in a new tab.

If there’s a new issue to link to the conversation, you can view a list of issues you’ve recently linked to other conversations or search your Linear projects in order to find just the right one. It’s possible to quickly link multiple issues from the search results and to view full issue descriptions to make sure you’ve got the right issue. If there’s not a Linear issue for what your customer is reporting, you can quickly create a new one and automatically link it to the current conversation.

## Configure[⁠](https://linear.app/integrations/helpscout.html#configure)

Help Scout administrators on the Plus and Pro plans can install the app from the Manage -> Apps listing.
