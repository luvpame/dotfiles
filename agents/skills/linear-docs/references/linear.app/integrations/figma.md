## Figma with Linear Agent[⁠](https://linear.app/integrations/figma.html#figma-with-linear-agent)

Share a Figma frame with Linear Agent to turn a design into implementation requirements, capture component details, or summarize a flow for a project brief.

You can also ask the agent to create or update designs in Figma using requirements from your issues. Link the resulting frames back to Linear for review and implementation.

### Configure[⁠](https://linear.app/integrations/figma.html#configure)

Connect Figma’s remote MCP server to Linear Agent and authorize access to your Figma account. The connection supports reading and writing to files you have permission to access.

Share a frame link to work with an existing design, or a file link where the agent can create a proposal.

[Learn about the Figma MCP server](https://developers.figma.com/docs/figma-mcp-server/)

## Linear plugin for Figma[⁠](https://linear.app/integrations/figma.html#linear-plugin-for-figma)

Create and link Linear issues to frames, sections, and pages directly from Figma. Open the plugin to see issues linked to your designs, check their status, and assign them to teammates.

When an issue’s status changes in Linear, the change appears in the plugin.

### Configure[⁠](https://linear.app/integrations/figma.html#configure-2)

In Figma, go to **Resources → Plugins → Linear** to install and run the plugin. It’s also available under Plugins in Dev Mode. Sign in with your Linear account to get started.

## Embed Figma previews[⁠](https://linear.app/integrations/figma.html#embed-figma-previews)

Paste a Figma link into a Linear issue or document to display a preview with the file name and a snapshot of the design.

Click the image to preview the file in Linear, or click the file or canvas name to open it in Figma.

### Configure[⁠](https://linear.app/integrations/figma.html#configure-3)

A Linear admin can connect the workspace’s Figma account in Linear’s integration settings. Once connected, everyone in the workspace can embed previews by pasting Figma links.
