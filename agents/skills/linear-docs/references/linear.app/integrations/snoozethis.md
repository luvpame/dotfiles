## Overview[⁠](https://linear.app/integrations/snoozethis.html#overview)

If you have an issue that cannot progress, add a comment telling SnoozeThis what you are waiting for. SnoozeThis will take over and hand the issue back to you at the right time.

## How it works[⁠](https://linear.app/integrations/snoozethis.html#how-it-works)

Installing the integration enables SnoozeThis to listen for mentions. Everything after “@SnoozeThis” will be parsed to determine why the issue needs to be snoozed. SnoozeThis will then unassign the issue, set the state to “Snoozed”, start monitoring the blocker and add a new comment with a short summary.

Later, when the snooze has been resolved (for example, when a GitHub issue has been closed), SnoozeThis will by default add another comment, reassign the issue and restore the state. Effectively, SnoozeThis will make the things that cannot progress disappear and have them reappear at the appropriate time.

## Configure[⁠](https://linear.app/integrations/snoozethis.html#configure)

As a Linear Admin, go to the [installation guide](https://www.snoozethis.com/linear/install) to add the integration to your workspace. SnoozeThis will then work for all members.
