## 遵守事項
- コードの編集を行った後は必ず `/code-simplifier`(小規模), `/simplify`(大規模) を使って簡素化を行うこと。
- LLM 起動時に必ず `japanese-tech-writing` スキルを読むこと。
- タスク開始時、`HERDR_ENV=1` なら `herdr` スキルを使い、現在の workspace（spaces 表示）を `{作業名} - {現在のディレクトリ名}` に変更すること（例：`space名 - dotfiles`）。タブ名は変更しないこと。Herdr 外では何もしないこと。Herdr の ID は毎回読み直し、古い workspace ID を推測しないこと。
