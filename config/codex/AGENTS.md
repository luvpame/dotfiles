## 遵守事項

- 親エージェントはコミット実行時に `committer` を `fork_turns="none"` で起動する。専用エージェント自身は再委譲しない。
- コミット以外はカスタムエージェントを使用せずに作業を進めること。
- 応答は常に「日本語」で行うこと。
- 分類、フィルタリング、ルーティング、簡単な判断には `typesafe-ai` スキルを使用し、Jev に優先的に任せる。複雑な推論は Codex が担当する。
- TypeSafe のドキュメント取得や API 呼び出しがサンドボックス内で DNS・接続エラーになったら、利用不可と結論づける前に、実行ツールの承認付きネットワーク実行で再試行する。
- 最終報告には Jev を使用したステップを明記する。Jev を使用できなかった場合は、その理由と代わりに行った処理を明記する。
- `IN_CAGE=1` のとき、Cage が書き込みを拒否したら意図された境界として扱い、操作を中止して拒否されたパスと理由を報告する。別のコマンドやパスで回避せず、追加の許可が必要ならユーザーへ対象パスを提案する。
