# WezTerm テーマ切り替え設計

## 目的

WezTerm の表示を Catppuccin Latte と Catppuccin Mocha の間で、キーバインドまたはコマンドパレットから切り替えられるようにする。

## 設計

- 起動時は現在と同じ Catppuccin Latte を使う。
- `Ctrl+Shift+L` とコマンドパレットの項目は、同じイベントを呼び出す。
- イベントはウィンドウの設定オーバーライドを使い、カラースキーム、背景グラデーション、タブ色をまとめて切り替える。
- 既存の設定オーバーライドがある場合は保持する。
- テーマ選択は永続化せず、再起動時は Catppuccin Latte に戻す。

## 確認

Lua の構文検査を行い、差分で既存のキーバインドと設定が維持されていることを確認する。
