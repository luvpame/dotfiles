# Pique 導入 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 署名済み Pique を全プロファイルの Home Manager パッケージとして導入する。

**Architecture:** GitHub Releases の `.pkg` をハッシュ固定で取得する小さな Nix derivation を作る。derivation は署名済みアプリケーションバンドルを展開するだけで、上流ソースを再ビルドしない。既存の `commonPackages` に追加して、両プロファイルへ配布する。

**Tech Stack:** Nix Flakes、nix-darwin、Home Manager、`fetchurl`、`xar`、`libarchive`

## Global Constraints

- Pique のバージョンは `0.1.0b5` とする。
- 取得元は `https://github.com/macadmins/pique/releases/download/v0.1.0b5/Pique-0.1.0b5.pkg` とする。
- 固定ハッシュは `sha256-bxzC1Yr7cg8m2pQqMu+o2tNXxdl1aD7OhbommYrqsHU=` とする。
- 上流ソースを再ビルドせず、上流のコード署名と公証を保つ。
- 新規依存は追加しない。

### Task 1: Pique パッケージを定義する

**Files:**
- Create: `nix/pkgs/pique/default.nix`

**Interfaces:**
- Consumes: `fetchurl`、`runCommand`、`xar`、`libarchive`。
- Produces: `$out/Applications/Pique.app` を含む Nix パッケージ。

- [ ] **Step 1: リリースアーカイブの展開形式を確認する**

Run:

```bash
pkgutil --expand-full /private/tmp/Pique-0.1.0b5.pkg /private/tmp/pique-expanded
test -d /private/tmp/pique-expanded/Pique-0.1.0b5.pkg/Payload/Pique.app
```

Expected: `Pique.app` が Payload に含まれる。

- [ ] **Step 2: 最小の derivation を作成する**

```nix
{
  fetchurl,
  lib,
  libarchive,
  runCommand,
  xar,
}:
let
  version = "0.1.0b5";
in
runCommand "pique-${version}"
  {
    nativeBuildInputs = [
      libarchive
      xar
    ];
    src = fetchurl {
      url = "https://github.com/macadmins/pique/releases/download/v${version}/Pique-${version}.pkg";
      hash = "sha256-bxzC1Yr7cg8m2pQqMu+o2tNXxdl1aD7OhbommYrqsHU=";
    };
    meta = {
      description = "Quick Look extension for syntax-highlighted configuration file previews";
      homepage = "https://github.com/macadmins/pique";
      license = lib.licenses.asl20;
      platforms = lib.platforms.darwin;
    };
  }
  ''
    xar -xf "$src"
    bsdtar -xf Pique-${version}.pkg/Payload
    mkdir -p "$out/Applications"
    mv Pique.app "$out/Applications/"
  ''
```

- [ ] **Step 3: Nix フォーマットを適用する**

Run: `nixfmt nix/pkgs/pique/default.nix`

Expected: 正常終了する。

- [ ] **Step 4: derivation を直接ビルドして検証する**

Run:

```bash
nix build --impure --expr 'with import <nixpkgs> {}; callPackage ./nix/pkgs/pique/default.nix {}'
test -d result/Applications/Pique.app
```

Expected: どちらも正常終了する。

- [ ] **Step 5: コミットする**

```bash
git add nix/pkgs/pique/default.nix
git commit -m "feat(nix): Pique パッケージを追加"
```
